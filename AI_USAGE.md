## Какие AI инструменты использовались
OpenCode Big Pickle
Unity MCP by CoplayDev
## Какие задачи передавались AI
- Разработка плана и документации
- Написание основной части кода
- Работа с mcp: Тестирование в playmode, анализ профайлера.
## Несколько ключевых промптов
- Составь план разработки по ТЗ.
- Напиши unit-тесты на модели и калькуляторы.
- Через Unity MCP запусти playmode-тест и проверь консоль на ошибки.
- Проанализируй снимок профайлера и найди узкое место.
## Какие части реализованы с помощью AI
- Основная часть gameplay-кода по слоям MVP + DI (VContainer): модели, сервисы, презентеры.
- Экономика, бусты, оффлайн-прогресс, сохранение (`SaveService`/`FileStorageService`).
- Абстракции и заглушки SDK: `IIapService`, `IAnalyticsProvider` и их реализации.
- Конфиг-провайдеры (`IGameConfigProvider` + ScriptableObject-ассеты).
- Unit-тесты (Boost, Economy, Machine, NumberFormatter, OfflineProgress).
- Работа через Unity MCP: PlayMode-тестирование, чтение консоли, анализ снимка профайлера.
